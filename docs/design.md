# Current interface

The existing Local Converter design is retained: Inter typography, charcoal dark theme, light theme, restrained red actions, rounded workspace panels and responsive navigation. Shared components live in `src/components`; layouts and theme styles remain in `src`.

Tool and information heroes use responsive frosted-glass artwork with a clear central area for readable headings. Home and converter heroes retain their cloud artwork and conversion controls. See [hero artwork](hero-artwork.md) and its [generation record](design-assets/glass-background-generation.md).

Tool workspaces share file selection, settings, results and contextual guidance. Mobile layouts stack the same controls. Existing keyboard access, focus, reduced-motion behavior and accessible decoration rules remain part of the implementation.

Historical reference screenshots and iteration notes were moved to the recovery archive described in [cleanup.md](cleanup.md). Future browser captures belong in `.artifacts/screenshots/`.
