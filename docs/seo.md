# SEO in the GitHub edition

The original project already provided prerendered routes, a sitemap, robots, canonicals, structured data and discovery files. This edition retains that system and improves the browser homepage title/description, WebSite description, repository identity and social-image accessibility metadata. Browser navigation and exported HTML use matching metadata.

The homepage targets the actual task, “Free Online File Converter,” and explains on-device processing. It does not claim support for every format. Tool-specific metadata and limits remain attached to the existing registry and guides.

The footer links to the source repository. README images show the real application with descriptive alternative text. No ratings, testimonials, search positions or traffic numbers were invented.

Retained foundations:

- Canonical origin: `https://localconverter.tech`.
- Crawlable HTML links and route guides before JavaScript runs.
- WebSite, WebPage/CollectionPage, supported WebApplication, breadcrumbs and item lists.
- Sitemap and robots sitemap declaration.
- Existing preview-host noindex rules and private activity exclusions.
- 1200 × 630 social card, favicons and manifest.

No ranking or indexing outcome is promised. No automated SEO audit or test suite was run during cleanup, as requested. These changes affect a new website build; publishing source alone does not update production HTML.

References: [Google JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [crawlable links](https://developers.google.com/search/docs/crawling-indexing/links-crawlable), [canonical URLs](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), and [image SEO](https://developers.google.com/search/docs/appearance/google-images).
