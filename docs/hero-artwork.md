# Hero artwork

Information and tool heroes use custom frosted-glass artwork with separate desktop and mobile WebP assets. Source PNGs and the exact generation prompts are preserved in [design-assets](design-assets/glass-background-generation.md).

Desktop: `src/assets/backgrounds/hero-glass-v2.webp` (2160 x 720). Mobile: `src/assets/backgrounds/hero-glass-mobile-v2.webp` (900 x 1200). Home and converter heroes retain their cloud artwork and actual format controls.

Decorative assets must leave headings readable, remain hidden from assistive technology and avoid receiving pointer events. Existing typography, spacing, themes and file workspaces are retained.

Historical visual checks are in the recovery archive referenced by [cleanup.md](cleanup.md). New browser captures are generated under `.artifacts/screenshots/`.
