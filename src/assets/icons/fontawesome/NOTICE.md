# Font Awesome Free 7.3.1

Original solid SVG icons by Fonticons, Inc., https://fontawesome.com/.
Icons: Creative Commons Attribution 4.0 International (CC BY 4.0).
Source: https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/solid
License: https://fontawesome.com/license/free

The original SVG paths and viewBoxes are unmodified. icons.json serializes those paths for inline React rendering; color and display size are provided by CSS. LICENSE.txt and original SVG notices are retained. The app also provides public/licenses/fontawesome.txt and attribution on its About page.

The file-image, rotate and chevron-down path data and viewBoxes were compared with the publicly rendered CloudConvert PNG-to-JPG page and match exactly. Other file category icons are from the same upstream release. No CloudConvert proprietary code or brand-logo assets are included.
